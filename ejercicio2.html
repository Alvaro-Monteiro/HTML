Ejercicio 2

Primera parte: Lista de definición (rellenar los <dd>)

Escribe una definición clara y breve para cada elemento.

<title>
Sirve para poner el titulo de la página web
<meta>
Este nos sirve para definir los metadatos de la web
<strong>
Nos sirve para darle importancia el texto que pongamos en esta etiqueta, a su vez se vera en negrita.
<ul>, <ol> y <dl>
Etiquetas que sirven para hacer listas desordenadas, ordenadas o de definición, en el propio orden.
<div>
Etiqueta para ordenar en bloque nuestro codigo.
<blockquote>
Etiqueta para hacer una cita en la página.
<pre>
Etiqueta la cuál sirve para que el texto escrito en ella tenga el formato del visual.

Segunda parte: Lista

  • Estructura básica de un documento
    1. Doctype y raíz
      • !DOCTYPE html
      • html lang="es"
    2. Cabecera (head)
      • title
      • meta charset="UTF-8"
      • meta name="description"
    3. Cuerpo (body)
      • Encabezados y párrafos
        • h1 … h6
        • p
      • Texto en línea
        • strong (importancia)
        • em (énfasis)
        • mark, small, s, sub, sup
  • Listas en HTML
    • No ordenadas (ul)
    • Ordenadas (ol)
    • Definición (dl)
      1. dt – término
      2. dd – descripción
    • Anidación de listas
      • Subtemas con ul; dentro de li
      • Subpasos con ol dentro de li
  • Enlaces e imágenes
    1. Enlaces (a href="..." target="...")
      • Internos (anclas con #id)
      • Externos (nueva pestaña con _blank)
    2. Imágenes (img src="..." alt="..." title="...")
      • Atributos obligatorios y accesibilidad
  • Agrupación y separadores
    • div para agrupar bloques
    • hr para separar secciones
    • blockquote para citas largas
    • pre para texto preformateado
